# 159338 碎股动态与涨跌停联合回测

主版本采用桌面「159338_碎股动态与涨跌停联合回测」的交易口径。默认每笔 1 个最小申赎单位，申购和赎回的基础阈值均为 0.17%。信号逐分钟扫描 09:35–11:29 和 13:03–14:57，申赎申请的最小间隔为 5 分钟。默认开仓期为 2025-01-02 至 2026-06-25，交收跟踪至 2026-07-22。[联合配置](../configs/159338_joint.json)

## 从仓库根目录运行

首次使用时，在 Windows CMD 里建立项目环境并安装依赖。

```cmd
py -m venv .venv
.venv\Scripts\python.exe -m pip install -e .
```

已有桌面数据布局时，先检查数据路径，随后运行完整回测。

```cmd
call run_159338_joint.cmd --check-only
call run_159338_joint.cmd
```

在已安装依赖的 Python 环境也可运行 `python run_backtest.py`。已有原桌面联合版配置时，可显式传入配置文件。

```cmd
call run_159338_joint.cmd --config "%USERPROFILE%\Desktop\159338_碎股动态与涨跌停联合回测\configs\159338_joint.json"
```

## 准备输入

配置文件里的相对路径以该 JSON 所在目录为基准。换机器或换数据目录时，可编辑联合配置的四项路径，也可在命令中传入实际位置。

| 输入 | 配置字段 | 内容 |
| --- | --- | --- |
| 申赎清单 | `pcf_root` | PCF 根目录，含 `159338` 子目录及每日 XML |
| 分钟行情 | `minute_root` | ETF 和股票的历史分钟行情根目录 |
| 碎股清单 | `odd_lot_holdings_path` | Excel 工作簿，工作表 `159338` 至少含「日期」「股票代码」「零股数量」 |
| 调整前收 | `odd_lot_reference_prices_path` | CSV，按 `time`、`thscode` 匹配当日的 `preClose` |

示例中的 `D:\ETF数据` 换成实际位置。先以 `--check-only` 检查配置，通过后去掉该参数即可运行。

```cmd
call run_159338_joint.cmd --check-only ^
  --pcf-root "D:\ETF数据\gtfund_pcf" ^
  --minute-root "D:\ETF数据\ifind_minute_close" ^
  --odd-lot-holdings "D:\ETF数据\碎股清单.xlsx" ^
  --odd-lot-reference-prices "D:\ETF数据\前收.csv"
```

要把申购基础阈值设为 0.18%、赎回设为 0.14%，在命令中传入比例值。两侧相同可使用 `--premium-threshold`。同时给出两类参数时，方向参数优先。

```cmd
call run_159338_joint.cmd --creation-threshold 0.0018 --redemption-threshold 0.0014
```

用 `--start-date` 和 `--end-date` 选取开仓日期，用 `--settlement-end-date` 指定最后交收观察日。三个日期均使用 `YYYY-MM-DD`，并须在配置提供的交易日历范围内。

## 同一分钟怎样判断申赎

1. 读取盘前可得的当日碎股清单。普通和允许替代股票的有效敞口股数取「零股数量 − PCF 浮动股数」，必须现金替代股票取「零股数量」，其 PCF 固定金额单列。逐股以有效敞口股数乘以「信号分钟价 − 当日调整前收」，合计加到盘前预估现金，得到每最小申赎单位的信号时估计现金。
2. 将 PCF 浮动股票市值、固定替代金额和信号时估计现金相加，再除以最小申赎单位份数，得到动态 IOPV。动态折溢价等于 ETF 信号分钟价除以动态 IOPV 再减一。缺少必要估值数据时，在 `signals.csv` 记录原因。
3. 动态折溢价幅度越过该方向的基础门槛后，申购查当分钟涨停股，赎回查当分钟跌停股。从有正股数且非固定替代的股票中，按本笔单股市值套用固定分档表。申购区分深市、沪市，赎回合并两市。将已确认触限的逐股预计亏损加总，限价或报价待核的股票单列。
4. **有效阈值 = 该方向基础阈值 + 方向性触限股票预计亏损合计 ÷ 动态整篮估值**。动态整篮估值为动态 IOPV 乘本笔 ETF 份额。申购溢价或赎回折价幅度必须严格超过有效阈值，随后检查申赎可行性等开仓条件。预计触限损失仅用于开仓判断，账户按实际模拟成交、费用和现金交收记账。

分档表沿用 159338 历史逐股纯价差校准，保留重复交易，校准窗口为 2025-01-02 至 2026-07-22，并剔除 2025-04-07 开仓样本。区间内全程使用同一组固定系数，重叠期结果属于样本内对照。[分档样本及算法](../profiles/159338_joint/etf_arb/rules/limit_loss_calibration.py)

## 在报告里核对一笔信号

每次运行会在仓库根目录的 `reports/dynamic_limit_loss_…/` 建立独立目录。打开其中的 `report/report.html` 看结果，或在同一运行目录的 `signals.csv` 按 `ts` 定位交易分钟。

| 字段 | 口径 |
| --- | --- |
| `pcf_cash_per_unit`、`cash_adjustment_per_unit`、`signal_cash_per_unit` | 盘前预估现金、碎股修正、信号时估计现金，单位为元／最小申赎单位 |
| `iopv`、`premium` | 动态每份估值、带正负号的动态折溢价 |
| `signal_basket_value`、`estimated_limit_loss` | 本笔动态整篮估值、预计触限亏损，均为元 |
| `base_threshold`、`limit_loss_threshold_addon`、`effective_threshold` | 该方向的基础门槛、涨跌停加点、最终门槛，均用比例表示 |
| `limit_loss_components`、`limit_loss_unknown_components` | 各股贡献和行情或限价待核明细 |
| `reason` | `below_limit_loss_threshold` 表示越过基础门槛后被加点拦下，`threshold_crossed` 表示通过信号检查 |

以 2025-02-21 14:37 的申购候选为例，1 个最小申赎单位的碎股现金修正为 +1,145.39 元，动态整篮估值为 2,943,775.36 元，动态溢价为 0.177481%。涨停股预计亏损合计 3,475.35 元，对应加点 0.118058 个百分点。最终门槛为 0.288058%，因此该分钟跳过。
