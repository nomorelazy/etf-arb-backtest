## 2026-11-04 买入腿前移至信号 t 分钟

用户要求在 GitHub 版本把赎回买入 ETF、申购买入股票前移至 t 时刻。默认 `entry_at_signal_time=true`，沿用 close 研究模型，入场 BUY 在信号分发的实际调用链中以 t 分钟精确 close 足额成交；缺当前分钟行情不使用旧价或后续价格替代。该项替换此前买入统一等待 t+1 的要求，不调整其他交易腿的既定时点。

申赎申请继续在首个后续允许分钟提交（market-split 模式为 t+1），正常赎回沪深股票仍在申请 t+1 分钟卖出，申购 ETF 仍在申请之后更晚的首个允许成交分钟卖出，通常为 t+2 分钟。现金替代股票按实际申请时间启动沪市窗口、T+2 定价及深市 14:30 补券；这些规则与入场买入分开。此前的同分钟赎回要求现仅作用于申请和股票卖出，ETF 买入前移到信号分钟。

整篮买入前预检精确行情、对应 BUY 权限、全部买入税费、申请款资金和已知的下一申请分钟许可，防止先买部分后发现无法完成该篮子。t 买入的资金和费用即时扣账，申赎申请款仍在实际申请时扣账；t+1 不再检查或重买已经买足的 ENTRY 证券，不用 t+1 价格重算其成本。申请时继续核对可用现金并禁止透支。频率从实际 applied_at 起算，仍为 60 分钟。无下一允许申请分钟时，不在 t 先买入。
